# OuDiaSecond読み込みの契約

対応は **OuDiaSecond.1.07 / OuDiaSecond.1.17 の部分集合**です。全版互換の宣言はしません。未知版、未知の列車条件、環状線、増解結は明示エラーとし、現在のプロジェクトを保持します。

## 構文・文字コード

`Name.` で階層を開始し `.` で終了します。項目は最初の `=` で分けます。BOM、CRLF/LFに対応。未閉鎖・余分な終端・意味を持つ重複キーはエラー。DispPropのJikokuhyouFont / DiaBackColor / JikokuhyouBackColorは既知の表示配列として繰り返しを許容します。これら表示値は解析に使わず、警告へ記録します。

文字コードは自動の場合UTF-8を厳密デコードし、失敗時だけShift_JISを試します。UIから明示指定も可能。実際に用いた文字コードはJSON内に保存します。

`Rosen > Eki / Ressyasyubetsu / Dia > Kudari・Nobori > Ressya` を読み込みます。複数Diaを保持し、駅・種別は共通です。複数Rosenは未対応です。完全に空のRessyaは空欄列として件数を記録して除外します。Houkou等がある非空列車の不正・欠落はエラーです。

## 時刻と運行日

カンマは方向順の駅区切りです。上りは路線駅順の逆。空欄の位置を保持し、省略された末尾は運行なし。駅数分の項目に続く区切りカンマ1個を許容します。

駅項目は `扱い;着/発$番線`。0=運行なし、1=停車、2=通過。時刻なしの通過も保持します。スラッシュなしの単独時刻は発時刻。`着/`、`/発`に対応します。着時刻を発時刻から推定しません。

HMM / HHMM / HMMSS / HHMMSSを受理し、分・秒0〜59、時0〜47を検証します。内部は運行日の00:00からの秒です。

解析起点はUIで「ファイルの起点」「00:00」「03:00」「04:00」から選択できます。既定はファイルのKitenJikoku、未指定なら00:00。これはファイルの描画起点に解析運行日を合わせる**明示的な解析規約**です。起点より前の明示時刻を+86400秒として扱い、規約と件数を警告・JSONに記録します。列車の途中で不整合な時刻逆転が残る場合はエラーとし、逆転を見てその場で翌日へ繰り上げる推測は行いません。元のEkiJikokuも保持します。

## 分岐駅と駅ID

`BrunchCoreEkiIndex` を基に基幹駅・派生行を同じ物理駅IDへ割り当てます。同名だけでは統合しません。参照範囲・循環を検証します。時刻表上の行ID `oud-p24` と物理駅ID `oud-s15` を分離しています。基幹駅より前の派生行は合流支線の終端、後の派生行は分岐支線の開始として、表示上の境界を横断する偽の隣接区間を作りません。

各列車の元の行別時刻は保持します。運行なしを除いた訪問順で連続する同じ物理駅があるとき、明示された最初の着時刻と最後の発時刻を同一駅の訪問として扱います。元の着発を同時刻に変えたり、新しい時刻を推計したりしません。これにより、琴町の基幹行で到着し派生行で発車する便や、葉南１丁目の合流を一つの駅として分析できます。一般の環状線はまだ拒否します。

## 路線外発着

OuterTerminalは境界駅に属するローカルな定義です。同じ名称でも別の境界駅に属するものは別IDとします。基幹・派生行は基幹駅の定義を共有します。派生行に独立定義があって共有関係が曖昧な場合は停止します。

駅作業 `Operation{方向順駅添え字}{B/A}` のコード4を解釈します。

- B：路線外始発駅の発時刻 → 当境界駅の着時刻。
- A：当境界駅の発時刻 → 路線外終着駅の着時刻。

路線外駅添え字を境界駅の定義と照合し、始発／終着作業が列車の境界にあることと時刻順を検証します。駅作業原文・境界時刻・外部時刻・外部駅IDを保持し、管理画面と直通一覧に表示します。運用番号は原文に保存し、運用再現には使いません。

**外部駅はStationに追加しません。** 人口やOD、外部の中間停車駅を推測しません。直通分析と費用計算は路線内のEkiJikokuに限ります。境界時刻が駅作業とEkiJikokuで一致しない場合は警告し、どちらも書き換えずに保持します。内部解析にはEkiJikokuを採用します。

## 運休・駅作業・未対応情報

Canceled=1は登録したまま、発車本数・直通・有効列車・待ち時間・ダイヤ費用から除外します。空欄列とは区別します。

駅作業0/3/5/6はコード・行・前後・原文を保持します。入換時刻を当駅着発に適用するフラグが1の作業、増解結1/2、入れ子作業、未知の列車フィールドは未対応エラーです。0/3/5/6の運用再現、前次列車接続を使うレコード間の旅客直通連結、途中種別変更は未実装です。

未知の非列車項目・描画・フォント・色・交差支障チェック・ウィンドウ設定は警告して解析に使いません。書き出しはプロジェクトJSONであり、原.oud2の完全な往復保存は未対応です。単独時刻の多い駅での到着OD、路線外OD、駅IDのファイル間自動対応も未対応です。
