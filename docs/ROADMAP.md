# MVP 0.7の優先順位

0.6で同時刻一括・FIFO／同着比例、時刻4方式、分割元付き旅客追跡と途中人数監査、11条件のシナリオ幅、比較条件と完了率の照合を追加した。0.5は `9b52aad` に保存した。

1. **P0：方式感度と時刻精度**。同時刻候補への提案ルール・候補上限の感度、同等便の端数、連続個人モデルとの収束試験。ゼロ所要連鎖は同時発車段階後の降車という規約を維持し、実時刻の根拠がある場合だけ精密化する。
2. **P0：乗換多数の検索性能**。110駅容量・徒歩ありは約23秒。発駅・路線走査、無意味な乗換候補とラベル生成の削減、キャッシュの保持メモリ計測を優先する。
3. **P1：結果の転送・描画**。停車情報の結果内共有を進め、Worker分割転送、OD・ログ表の仮想スクロール、Worker単独ヒープ測定を追加する。
4. **P1：実測検証と比較範囲**。時間帯別の独立観測、目的・往復・日区分の対応、推計誤差の条件整理。シナリオ幅を統計的信頼区間と混同しない。共通輸送者だけの平均で改善を主張しない。
5. **P2：運行・需要モデル**。根拠のある直通・増解結、遅延・車両運用、経路相関、ゾーン・他交通機関。未確認の実路線接続は生成しない。
